# aromaguide
Бот для подбора селективной парфюмерии
### Стек технологий / Инструменты:
* **n8n — разработка сценариев автоматизации и логики бота.
* **Telegram API** — основной канал взаимодействия с пользователями.
* **Google Sheets / Airtable** — база данных для хранения информации об ароматах и пользователях.
* **JSON** — работа со структурами данных и вебхуками.
